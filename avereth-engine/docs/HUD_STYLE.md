# HUD controls in SillyTavern

The status and recovery row precedes the current composer. Put a live story action there once per chat. Historical replies may show their recorded party and resources. Read current availability and the active revision again when a player commits a choice.

Use the existing composer, action-controls or inline party-panel button scope for contrast, disabled, hover and keyboard focus states. Use the shared `avereth-shop` class for disclosure rows alongside Rest and Known Routes. SillyTavern can prefix classes in rendered messages with `custom-`. Check both rendered markup and the native composer in the isolated host.

For a HUD change, check the latest versus older messages, keyboard focus, narrow widths, stored versus pending state and a reload. Opening a read-only panel leaves chat, time and model calls unchanged.
