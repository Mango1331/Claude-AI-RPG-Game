# Alderwatch .210

Ein neuer Magier schloss sich mit Brannoc und Merrin für Old Crown zusammen. Er lieh den Schlüssel von Serra, kehrte angesichts dreier Skelette um und nahm die Kopie eines Berichts an. Die folgenden Züge betreffen die Übernachtung, die Suche nach Serra und die Verantwortung für das Schriftstück.
