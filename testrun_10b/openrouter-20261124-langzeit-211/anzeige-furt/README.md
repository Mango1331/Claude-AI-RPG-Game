# Vorzeigen und Rückgabe am Ford

Unabhängiger Besitzkandidat, aus Halloran .211 nach Eingabe 12. Acht natürliche Züge. Am Ford blieb das Tuch beim Vorzeigen bei Alaric, die spätere Rückgabe war möglich. Berta bot eine Mitfahrt an. Auf dem Weg musste sie vor Wegelagerern wenden. Die Rückkehr zu den Hallorans stand beim Beobachtungsende noch aus.
