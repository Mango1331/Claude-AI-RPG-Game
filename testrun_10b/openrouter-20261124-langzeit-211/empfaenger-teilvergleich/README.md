# Empfängerangabe im Extractorprompt

Vier natürliche Extractorantworten zu genau derselben gespeicherten YA7-Narration. Die einzige Eingabedifferenz in zwei Antworten sind die IDs des bereits übergebenen Berichts und seiner Empfängerin. Keine neuen vollständigen ST-Spielzüge.
