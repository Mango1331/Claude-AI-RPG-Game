# Halloran .211

Alaric brachte Ring und Nachricht zu Wren, ging mit ihr zurück und suchte später Dann am Ford wieder auf. Aus einer gefährlichen Karrenquerung entstand ein Streit um ein überschwemmtes Feld. Ob Brigid, Dann und Tomen später den richtigen Helfer und den Grund des Schadens kennen, wirkt sich unmittelbar auf das Spiel aus.
