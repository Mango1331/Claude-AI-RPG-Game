# Serras Leihschlüssel am Dungeonroot

Vier frische, einzeln bezahlte Extractorantworten auf den gespeicherten GA8-Request. In AB/BA-Reihenfolge enthielt ausschließlich B am Kontinuitätseintrag der abwesenden Serra zusätzlich ID und Bezeichnung ihres bereits gespeicherten Schlüssels. Der ursprüngliche und der probeweise erweiterte Katalog verarbeiteten anschließend dieselben vier Antwortkörper offline. Die drei zusätzlichen Fernbesitzfälle sind vollständig synthetische Negativkontrollen.

| Request | Zusätzliche ID im Prompt | Ergebnis mit regulärem Katalog | Mit experimenteller ID-Freigabe |
|---|---|---|---|
| 517 | nein | Ungültige Neuanlage ohne Menge | Gleich |
| 518 | ja | Modell wählt exakt das Original nach Serras Eintritt, Parser fordert Repair wegen nicht sichtbarer ID | Dieselbe ID gelangt an den PC |
| 530 | ja | Zweiter Schlüssel | Zweiter Schlüssel |
| 531 | nein | Zweiter Schlüssel | Zweiter Schlüssel |

Im negativen Nachspiel bleibt Serra an ihrer Hütte. Der erweiterte Katalog erlaubt, den Schlüssel der abwesenden Frau an Merrin oder auf den Boden beim PC zu versetzen. Nur die Übergabe an PC selbst scheitert an der Präsenzprüfung. Der Ansatz wurde verworfen. Der Diff im Forschungsordner dient ausschließlich der Reproduktion der Gegenprobe. Die Rollenteilprüfungen enthalten keine nachgeschaltete kostenpflichtige Reparatur.
