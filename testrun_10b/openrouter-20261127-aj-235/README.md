# Echte Rückfrage an den Gesprächspartner

AJ1 erhält eine zweite erzählte Zustimmung. Erneut bleibt die mechanische Aufnahme an der Sprecherpassage hängen. AJ2 lässt den Planner die benannte gemeinsame Reise wählen. Der Interpreter entfernt sie als npc_actor, die Ankunft wird abgelehnt. Die Prosa zeigt beide an der Kapelle, während die Engine sie weiter in der Gildenhalle führt.
