# Warten und Wiederaufnahme nach der Gildenabgabe

AK1 erkennt die an Ossen gerichtete Bitte im Planner. Der Interpreter entfernt sie als npc_actor. Die Erzählung lässt Ossen auf der Bank zurück, der Mitgliedsmodus bleibt follow. In AK2 erreicht Alaric allein den Markt. AK3 erreicht mechanisch die Gilde, in AK3/4 ist Ossen dort abwesend. Die Bitte zur Wiederaufnahme kann daher keine bestätigte Wiedervereinigung erzeugen. Die schon gezahlte Vergütung bleibt gebucht. [Originale](SOURCE_MANIFEST.json)
