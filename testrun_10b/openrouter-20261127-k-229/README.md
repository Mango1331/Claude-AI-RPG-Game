# Zwei Dienstleistungen am Copper Kettle

Am unveränderten User15-Angebot wählt der Spieler im nativen Handel beide Zeilen. Genau ein Kauf senkt den Geldbeutel von 224 auf 219 cp, schreibt Unterkunft und Mahlzeit und lässt die Uhr auf Minute 1170. Der erste kombinierte Folgezug mit Ortswechsel, Ablegen des Stabes und vier Stunden Schlaf lässt den Schlaf wegen ausstehender Ankunft offen, obwohl die Prosa bereits das Bett schildert. Auf die alleinige Schlafentscheidung steigt die Uhr auf 1410. [Eingaben, Save und Providerabrechnung](SOURCE_MANIFEST.json)
