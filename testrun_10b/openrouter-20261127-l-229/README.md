# Fortsetzung auf Ebene 1 und Nachweis der widersprüchlichen Ankunft

Drei direkte Spielereingaben zur nächsten Kammer führen zu drei erzählten Übergängen. GO hat jeweils Sektion 3 autorisiert. Der Extractor gibt für die bestätigte Ankunft denselben Ort an, den die Gruppe verlassen wollte. Nach jedem Neuladen steht sie weiterhin in Sektion 2.
