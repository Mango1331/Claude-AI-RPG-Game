# Sichtbare Goblins als unerreichbare Fernmeldung

Am ursprünglichen User16-Türpfosten beschreibt X beide Goblins und nennt sogar die exakte Begegnungsreferenz. Es meldet aber present:false ohne across. Der Save enthält zwei Fernmeldungen, der Begegnungsslot bleibt leer. Der ausdrücklich gewählte Flame Lance auf den Messerträger endet im nativen TARGET NEEDED. Mana bleibt bei 41. Die anschließende Beobachtung ändert diese Zuordnung nicht. [Quellenmanifest](SOURCE_MANIFEST.json)
