# Individueller Gegenstand und tatsächlicher Pelzverkauf

S1 und S2 zeigen für Anzeigename und ID denselben getragenen Superior F-Rank Sceptre mit MATK 18. Beide Aufrufe bleiben lokal. S3 erreicht den Markt, S4 den Käufer und ein verbindliches Gebot. Ein zusätzliches Angebot ohne gültigen Betrag wird abgewiesen. S5 nimmt das gültige Gebot an. Die 80 cp werden tatsächlich einmal gutgeschrieben, der Geldbeutel steigt von 380 auf 460 cp.
