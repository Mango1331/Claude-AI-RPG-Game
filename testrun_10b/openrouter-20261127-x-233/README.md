# Gebührenanspruch und unbestätigte Trennung

In X1 bittet Alaric um Trennung und verspricht, mit Ossens Anteil zurückzukehren. Der Plannerbeleg führt zur Rückfrage. X2 nennt die alleinige Rückreise. Mechanisch folgt Ossen weiterhin und erhält die 45 cp direkt bei Abgabe. Die Quest ist korrekt abgeschlossen. Eine offene Schuld oder gelungene Trennung kann aus der Erzählabsicht nicht abgeleitet werden. [Originalzustände und Kosten](SOURCE_MANIFEST.json)
